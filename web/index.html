    Editable source

    Transcript

    Bring your own provider

    Remote transcription

    Send one selected audio file to an OpenAI-compatible transcription endpoint. The endpoint, model, and API key stay in page memory; Tutorux has no hosted proxy.

    Before sending

    Only the selected audio file and the API key (in the Authorization header, if entered) leave this device. Tutorux does not send archive data, existing transcripts, notes, or other files. The provider may process or retain the upload under its own terms.

    Choose audio to review the per-upload disclosure.

    Choose a session to view transcript segments.
    Session audio

    Recording

    Browser recording uses the source selected when the journal session was created. System audio requires browser tab or screen sharing support.
    Choose a session to view its recording tracks.

    WAV import only; browser imports are limited to 64 MiB per file. Browser microphone captures are stored in the archive as native audio chunks.

    Choose a session to view or import its recording.
    Session sources

    Files and media

    Each browser import is limited to 64 MiB per file. Supported images, PDFs, text, audio, and video can be previewed in the archive with format-specific size limits. Originals remain unchanged. You can also drop files anywhere in Tutorux.

    Choose a session to view its files and media.
    Student-ready materials

    Study guides

    Create evidence-linked drafts from a session, revise each section, review its sources, and keep tutor decisions distinct from recommendations.

    Human-reviewed handoff

    External AI package

    Download a session package, use it with an external agent, then import its JSON guide response for tutor review. The browser does not send session data to an AI provider.

    Open an archive to view study guides.
