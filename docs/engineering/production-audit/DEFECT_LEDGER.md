# Defect ledger

Audit date: 2026-11-04. Severity is user impact, not effort.

| ID | Component | Severity | Expected | Actual | Root cause | Classification | Correction | Regression evidence |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| D-01 | Archive recovery | High | The newest committed generation is found after a crash tail | A locator starting in the 31-byte scan overlap was ignored; `recover --discard-tail` could remove a committed generation | Candidate filter required `offset >= chunk_start`, although the overlap was read for exactly this case | FIXED | Accept overlap candidates; overlap fallback scans in `commit_published_end` | `locator_straddling_a_recovery_chunk_boundary_is_found` |
| D-02 | Compaction / encryption | High | Archives with audio imports can be compacted and encrypted | Duplicate empty-content BLOB aliases made rebuild fail | Rebuild rejected all duplicate secondary aliases; identical blob content legitimately shares a BLOB alias | FIXED | BLOB aliases keep the first matching record; other alias conflicts still fail | `compaction_accepts_duplicate_content_hash_aliases` |
| D-03 | Compaction pruning | Medium | Referenced audio placeholder blobs survive pruning | Audio-track/take `blob_id` references were skipped and their blobs were deleted | Retained-set builder skipped audio metadata roles | FIXED | Retain existing audio metadata blob references without failing legacy archives | `compaction_keeps_placeholder_blobs_referenced_by_audio_metadata` |
| D-04 | Sanitized copy | Medium | Crafted guide text cannot crash sanitize | A multibyte character at the fixed UUID offset caused a UTF-8 slice panic; unbounded counts could hang | Sanitize duplicated a fixed-width parser and used unbounded section counts | FIXED | Reuse boundary-safe guide parsers and the 10,000 count bound | `inline_source_parser_does_not_split_a_multibyte_character`, `oversized_section_and_block_counts_are_rejected_quickly` |
| D-05 | Command console | High | Console mutations apply to the open archive | Every write failed with `archive_locked` | CLI tried to acquire a second exclusive OS lock while the desktop held a shared lease | FIXED | Thread-local ambient lock registration lets the CLI upgrade and reuse the desktop lease | `replace_existing_reuses_an_ambient_desktop_lock` |
| D-06 | Save publication | Medium | A preserved recovery copy is never deleted by cleanup | Cleanup deleted the backup directory whenever a destination existed, even when restore failed | Cleanup inferred success from `target.exists()` | FIXED | Remove the backup directory only when `previous-archive` is gone | `failed_save_keeps_a_recovery_copy_that_could_not_be_restored` |
| D-07 | Save identity | Low | A deleted destination can be recreated by Save As | A stale in-memory identity blocked publication | Expected identity was returned without checking destination existence | FIXED | Return no expected identity when the destination is absent; publish based on actual target existence | `deleted_destination_does_not_keep_a_stale_expected_identity` |
| D-08 | Crafted archive arithmetic | Low | Crafted generations/revisions cannot panic or silently skip a commit | `u64::MAX` generation overflowed in debug or wrapped in release; verification comparisons could panic | Unchecked `+ 1` arithmetic in archive and verification paths | FIXED | Checked arithmetic with explicit errors; verification uses `checked_add` | Existing mutation/fuzz suites plus checked paths in `cargo test` |
| D-09 | CLI stale writes | Medium | An external in-place change is not silently overwritten | Expected bytes could be reread from the changed file, so a same-size external rewrite passed the guard | `save_replacing` and maintenance read expected bytes from a live file source | FIXED | Re-parse the expected image and require the loaded header/commit identity before saving | Existing CLI lifecycle corpus plus `cargo test` |
| D-10 | AI transport | Medium | Fixed provider hosts reject non-default ports | A key could be sent to `api.openai.com:<arbitrary port>` | Host validation ignored the URL port | FIXED | Require no explicit port for fixed providers; custom compatible endpoints remain flexible | `fixed_provider_hosts_reject_non_default_ports` |
| D-11 | CLI AI credentials | Medium | A custom endpoint cannot use another provider's keychain key | Keychain fallback was attempted for `openai-compatible` | CLI bypassed the desktop endpoint/credential guard | FIXED | Disable keychain fallback for custom compatible endpoints and restrict `--api-key-env` to the provider's documented variable | Rust tests and CLI parity |
| D-12 | Desktop CSP | Medium | Ollama discovery/connection checks work in the desktop app | CSP blocked `http://127.0.0.1` fetches | Desktop CSP omitted loopback sources already present in the browser CSP | FIXED | Add loopback `connect-src` entries | CSP unit test and desktop build |
| D-13 | Desktop IPC hardening | Medium | Renderer IPC only writes allowed export types and never executes arbitrary binaries | Save/export accepted arbitrary paths and FFmpeg accepted any executable path | Commands lacked window checks and export/executable validation | FIXED | Main-window checks, export extension/startup-directory guards, FFmpeg basename validation | Rust export/audio tests, `cargo clippy` |
| D-14 | Archive switching | High | Unsaved work and open drafts are not discarded by opening another archive | Opening/creating an archive replaced the workspace without saving; open forms could write stale records into the new archive | No dirty/editor/dialog guard before workspace replacement | FIXED | Refuse replacement while dirty, a guide editor or a dialog is open; clear transient dialogs on accepted switches | Playwright workspace and dialog suites |
| D-15 | Background commits | High | A recording checkpoint or Whisper commit does not close an unrelated form | Every `addRecords` closed dialogs and confirmations | Background and foreground writes shared one UI side effect | FIXED | Background commits opt out of transient-UI cleanup | Playwright AI/guide/recording workflows |
| D-16 | Save responsiveness | High | A save cannot replace newer workspace state with an older snapshot | Save completion overwrote a newer snapshot and marked it clean | Save used a pre-await workspace value unconditionally | FIXED | Re-read the active workspace; mark dirty when a newer generation appeared | Playwright save/reopen flows |
| D-17 | Archive health | Medium | “Save a copy” creates a separate file | It overwrote the current archive on desktop | Button used the ordinary save action | FIXED | Route the not-dirty button to Save As | Playwright archive flows |
| D-18 | Encrypted lock | Medium | Locking removes all record-derived state from the workspace | Settings, AI jobs and trashed audio metadata remained visible | Lock resets were incomplete | FIXED | Clear every record collection on lock | Playwright encrypted archive test |
| D-19 | Transcript editing | Medium | Editing text alone preserves an untimestamped cue | The cue became timestamped at `00:00:00` | Editor populated zero-valued times for untimestamped cues | FIXED | Leave time inputs empty unless the cue is timestamped | Transcript unit/E2E coverage |
| D-20 | Sanitized copy privacy | Medium | Snapshot updates do not silently widen the selection to all records | Any snapshot change reset the selection to “all” | Inventory loading reset privacy choices | FIXED | Preserve choices and prune only records that no longer exist | Sanitized-copy Vitest/E2E coverage |
| D-21 | Session packages | Low | A close failure cannot leave the UI permanently busy | `finally` awaited a rejecting close and skipped `setBusy(false)` | Missing catch in cleanup | FIXED | Catch close errors and always release the busy state | Typecheck and package E2E |
| D-22 | AI response import | Low | “Auto” preserves the response template | Auto was replaced with `general` before import | Wrong selector mapping | FIXED | Pass `auto` to the import service | Vitest AI import coverage |
| D-23 | Browser AI errors | Low | Timeout/offline failures are distinguishable from CORS | All fetch failures reported a CORS hint | Catch block collapsed causes | FIXED | Report timeout, offline, and CORS failure separately | `browser.test.ts` |
| D-24 | Recording recovery control | Low | Recovery is disabled during browser capture | A plain variable never updated the disabled state | Non-reactive state | FIXED | Use the existing capture-state signal | Transcript E2E/unit coverage |
| D-25 | Console recording | Low | The console does not launch the GUI instead of a worker | `record start --detach` reopened the desktop app | Detached worker used `current_exe` | FIXED | Reject console recording and direct users to the Record workspace | `console_recording_start_is_rejected_even_with_detach` |
| D-26 | Single-instance launch queue | Low | Repeated local launches cannot grow pending state without bound | The pending archive queue was unbounded | No queue cap | FIXED | Cap pending launch archives at eight | `cargo check` / startup flow tests |

No duplicate findings were counted twice. Findings that required a renderer compromise and remained architectural (for example, the console intentionally exposes the CLI surface) are recorded in `RELEASE_GATES.md` as residual risks rather than silently treated as fixed.
